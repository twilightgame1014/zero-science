# GPT 画像素材の不足分依頼（環境セット、2026-11-07・Muse から）

既存素材の棚卸し結果：森林土・草地・砂（乾/湿）・広葉樹の枝葉
4役・針葉樹・低木・草花・樹皮・倒木断面・雪・火山灰・玄武岩・
溶岩・水辺植物は既存の GPT 素材で足りています（再制作不要）。
不足は以下の6点だけです。いずれも今ラウンドの制作は既存素材と
プロシージャルで先行しており、到着後に差し替える前提です
（仮素材として本番完了扱いはしません）。

共通ルール：強い陰影や照明を描き込まない／文字・ロゴなし／
既存商業ゲームの模倣なし／Normal Map は描かない（Muse 側で作成）。

---

## 1. cliff-face（崖面）

- 用途・地域：山岳の崖部品（cliff-straight/concave/convex/top/bottom）の表面
- 現状：石積み壁のテクスチャで代用中（人工物に見えるのが問題）
- 解像度：1024×1024、上下左右シームレス
- 描くもの：自然な岩の層理（横方向の弱い縞）、割れ目、風化した面。
石を積んだ継ぎ目・直線的な目地は描かない
- 実寸感：1024px ＝ 実寸 2m 四方（岩の層は 20〜40cm 間隔）
- 配色：灰〜灰褐色。苔は別素材（3番）で重ねるので描かない
- バリエーション：1枚（色違いは Muse 側の色調整で対応）

## 2. ground-scree（山の斜面の地面）

- 用途・地域：山岳の植生の少ない斜面の地面ブレンド用
- 解像度：1024×1024、上下左右シームレス
- 描くもの：大小の岩片が混ざる礫まじりの土。大きな平らな色面を作らない
- 実寸感：1024px ＝ 実寸 6m 四方（岩片は 5〜30cm）
- 配色：灰褐色〜土色。草は描かない（ブレンド側で混ざる）
- バリエーション：1枚

## 3. moss-patch（苔パッチ）

- 用途・地域：岩の上面、倒木、森林の地面に重ねる苔のむら
- 解像度：1024×1024、純白背景（白→透過変換します。苔自体に白は使わない）
- 描くもの：縁が不規則に切れた苔のかたまりを1枚に4〜6個、
互いに重ならないように配置
- 配色：黄緑〜深緑のむら。胞子体の赤茶の茎を少しだけ
- バリエーション：1枚

## 4. waterfall-streaks（滝の水筋）

- 用途・地域：滝キット WF_Fall の流れ模様（現状はシェーダー生成で代用中）
- 解像度：1024×1024、純黒背景、水筋は白〜薄青で描く
（黒→透過として使います。水筋の中に黒を描かない）
- 描くもの：縦方向に流れる水の筋と細かい飛沫の粒。
上端から下端まで模様がつながる（縦シームレス）
- 密度：筋は画面幅の 60〜70% を覆う程度。全面真っ白にしない
- バリエーション：1枚

## 5. foam-set（泡のかたまり）

- 用途・地域：滝つぼの泡（WF_Foam）、川の瀬の泡
（現状はプロシージャル生成で代用中）
- 解像度：1024×1024、純黒背景、泡は白で描く
- 描くもの：大小の泡が集まった塊を4個、輪になった泡の帯を2個、
互いに重ならないように配置
- バリエーション：1枚

## 6. shore-foam-strip（水際の泡の帯）

- 用途・地域：海岸・湖畔の水際の泡ライン
- 解像度：1024×256、横方向のみシームレス、純黒背景、泡は白
- 描くもの：帯の下端に寄った泡の列と、まばらな泡の粒。
上端は無地（透明に抜ける）
- バリエーション：1枚
