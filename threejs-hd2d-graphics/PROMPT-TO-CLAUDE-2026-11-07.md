## 2. §16 への回答（4点）

1. **溶岩が読めない** → dq3 の lava-flow ペア（暗い地殻＋
   一条の明るい流れ、emissive は流れのみ、強度 1.5＋脈動）に
   差し替え済み。クレーターの溶岩湖と溶岩ノードの両方で
   優先使用。火山エリアの照明プリセットも明るく調整した。
2. **溶岩の上に景観の草** → モジュールの景観（草・野花）は
   エリア重みで抑止済み（volcano > 0.12 / snow > 0.62 は
   置かない）。ゲーム側 nature 配置は対象外なので、溶岩湖
   （火口中心 r≈8.2）の除外は、ゲーム側の配置で火山エリア
   中心 ±10 m を目安に除外をお願いします。
3. **NPC に遮蔽フェードが効かない** → 実装済み。
   setNpcVisualState の NPC が木・岩・建物の裏で opacity
   0.35 まで減衰する（プレイヤー用フェードと同じ区間テスト・
   半径。診断値：区間距離 0.4 < 半径 1.89 で減衰を確認）。
4. **建築プレビュー／エリア環境／地形9倍** → ラウンド18で
   実装済み。実ゲーム（feature/game-world-build に重ねた
   ビルド）で新API 5点が関数として見えることと、カメラUI
   （回転・上下角・ズーム・距離・「標準」）の表示・動作を
   確認済み。setStructurePreview / setEnvironment の
   ゲーム側採用をお願いします。

## 3. ラウンド18の統合手順

- 成果物はブランチ `feature/graphics-world-areas`。
  src/graphics への取り込みは従来どおり（両ツリー同期済み）。
- `src/terrain-entry.ts` に共有データの再輸出を1行追加して
  ください：areaWeights / areaDefinitions（DEFAULT_AREAS）。
  エリア定義の単一の正はモジュール側 utils の DEFAULT_AREAS
  （forest (0,0,78) / lakeside (108,−6,42) / coast (172,6,58)
  / volcano (−128,−118,62) / snow (108,−128,66) /
  desert (−128,118,66) / town (108,108,46)）。
  旧120 m 範囲の高さは不変であることを数値で証明済み
  （max |Δh| = 0.0000）。
- カメラ：setCameraView(view, {transition, temporary}) /
  getCameraView() / restoreCameraView() が使えます。
  移動方向とスプライト向きは getCamera() の実方向から計算
  する前提です（実装済みと認識）。
- setQuality('low' | 'high') で実行時の品質切替ができます
  （ピクセル比・影・ポスト・粒子・地形詳細）。

## 4. ラウンド19（DQ3素材）の統合手順

- GLB 21点は `assets/gpt-dq3/models/`（原点＝地面中心、
  正面 +Z、寸法は models-measured.json）。registerFactory で
  hut-town / plaza / 小物11点 / 広葉樹3種 / 玄武岩3種が
  使えます。現状は「素材制作完了・ゲーム導入未完了」。
- GLB はテクスチャ埋め込みで合計約17 MB。そのまま入れず、
  ラウンド14と同様の軽量版（albedo 512 JPEG、
  normal/roughness 256）生成を推奨します。
- 文明段階の分類（オーナー §9）：石畳・瓦屋根・木組み・
  小屋・広場・小物類は「発展した街」専用です。原始の開始
  集落には置かないでください。表示タイミング・解放条件は
  ゲーム側の判断で決めてください（グラフィクス側は進行
  ルールを持ちません）。
- 素材の対応表は `assets/gpt-dq3/README.md`、モジュール
  側の統合詳細は INTEGRATION §25。
