# 科学系UI デザイン仕様（2026-11-11 ラウンド納品）

コンセプト：**「文明再建を進める科学者のフィールドノートと実験器具」**
探索画面（HD-2D・夕景）と調和する、濃紺と生成りの静かな道具箱。
近未来SFのネオンにも、羊皮紙一色の古文書にも寄せない。

実装は Claude 側（ui.js）。本書は配色・寸法・状態表現の正本。
アイコンは既存の確定アセット `assets/ui-icons/`（GPT生成シート仕上げ済み、
192マスター＋48/32実寸版）を使う。本ラウンドで新規に描き直さない。

---

## 1. カラー

| 役割 | 色 | 用途 |
|---|---|---|
| `bg-deep` | `#0C141C` | 画面端・シート背面の影色 |
| `panel` | `#16212E` | パネル地（濃紺） |
| `panel-raised` | `#1D2B3A` | 選択中タブ・ホバー・カード |
| `panel-inset` | `#101A24` | 一覧の溝・入力欄・無効ボタン地 |
| `line` | `#2E4256` | 細い区切り線（基本はこれ） |
| `line-strong` | `#3D5A74` | パネル外周・フォーカス補助 |
| `text` | `#EDE6D2` | 本文（生成り） |
| `text-2` | `#B4BBA9` | 補助テキスト |
| `text-3` | `#77879A` | メタ情報・未発見 |
| `teal` | `#3FA08E` | 青緑：選択・リンク・実行可能 |
| `teal-bright` | `#57C2AC` | フォーカスリング |
| `amber` | `#D9A441` | 琥珀：重要な実行操作（主ボタン）だけ |
| `amber-deep` | `#B97F26` | 主ボタンのホバー/押下 |
| `warn-red` | `#C05B4D` | 材料不足（テラコッタ寄り、蛍光色にしない） |
| `state-gray` | `#5C6B7A` | 未発見・無効 |

原則：
- 琥珀は「押すと何かが起きる主操作」にだけ使う。装飾に使わない。
- 状態色はチップの地色ではなく、**左端3pxの縦線＋文字色**で示す（一覧が色だらけにならない）。
- 背景模様を使う場合も `panel` との明度差 ±3% まで。文字の背後に模様を置かない。

## 2. 形・余白・文字

- 角丸：パネル 10px／カード 8px／ボタン 6px／チップ 4px。**大きな丸角は使わない**。
- 影：使わない。階層は地色の明度差と 1px の `line` で作る。
- 余白スケール：4 / 8 / 12 / 16 / 24 / 32px。これ以外の余白を作らない。
- 文字（UIテキストは画像化せず Claude 側で描画）：
  - 画面タイトル 17px / 600
  - 見出し（セクション） 11px / 600 / 字間 0.14em / `text-3`（小さな目盛り線を左に添える）
  - 本文 14px / 行間 1.55
  - 一覧の名前 14px、メタ（所持数・条件） 12px / `text-2`
  - 数字は等幅寄せ（`font-variant-numeric: tabular-nums`）
- 装飾は「細い区切り線」と「セクション見出し脇の小さな目盛り（14pxの線）」だけ。
  絵文字・大きなアイコン装飾・グラデーション帯は使わない。

## 3. タブ（研究室／工作／図鑑／記録／地図／設定）

アイコンは `assets/ui-icons/` の lab / craft / encyclopedia / journal /
map / settings（＋ technology / base を追加タブ用に確保済み）。

| 状態 | 見た目 |
|---|---|
| 通常 | 地 `panel`、アイコン不透明度 0.55、ラベル `text-2` |
| ホバー | 地 `panel-raised`、アイコン不透明度 0.85 |
| 選択中 | 地 `panel-raised`、**左端に teal 3px の縦線**、アイコン不透明度 1、ラベル `text` |
| フォーカス | `teal-bright` 2px アウトライン（内側 offset −2px）。選択中とは別に必ず出す |

- アイコン自体の色は変えない（フルカラーのドット絵が正）。状態は地と縦線と文字で示す。
- PC：左レール型（幅 64px、アイコン 32px＋ラベル 10px）。
- スマホ：下部ナビ型（第6章）。

## 4. 状態表現（素材・レシピ・設備）

一覧行（高さ 44px、左：状態縦線 3px／アイコン 32px／名前／右：所持数などのメタ）。

| 状態 | 縦線 | 名前 | 右メタ | 詳細側の主ボタン |
|---|---|---|---|---|
| 実行可能 | `teal` | `text` | 必要数／所持数（`text-2`） | 琥珀「つくる／実験する」有効 |
| 材料不足 | `warn-red` | `text` | 不足分を `warn-red` で「あと2」 | 無効（`panel-inset` 地＋`state-gray` 文字）＋不足の一覧を赤字でなく `warn-red` の小見出しで列挙 |
| 設備不足 | `amber` | `text` | 必要な設備名（`amber`） | 無効＋「○○が必要」と設備名を明示（タップで設備の図鑑へ飛べるなら teal リンク） |
| 未発見 | なし | `text-3` で「？？？」 | 空欄 | 詳細を開かない（行自体が無効）。シルエット化したアイコン（不透明度 0.35＋ grayscale）だけ見せる |

- 「未発見」は存在自体を隠さない（図鑑のコレクション性のため）。ただし名前・説明は伏せる。
- 状態は色だけに頼らない：縦線＋メタ文字＋ボタン状態の3点で冗長に示す。

## 5. 詳細表示とボタン

- 詳細ヘッダー：アイコン 48px（`panel-inset` の角8pxの溝に置く）＋名前 17px＋分類タグ（4px角チップ、地 `panel-raised`、文字 11px `text-2`）。
- 本文ブロックは `line` の区切りで分け、各ブロック冒頭にセクション見出し（第2章の目盛り付き）。
- レシピ行：素材アイコン 24px＋名前＋「必要数／所持数」。不足行は名前でなく**数値だけ** `warn-red`。
- 主ボタン：高さ 44px、地 `amber`、文字 `#20180A` 600、角 6px、影なし。
  ホバー `amber-deep`。無効時は地 `panel-inset`＋文字 `state-gray`＋理由を直下 12px で明記。
- 副ボタン：透明地＋`line-strong` 1px 枠＋`text`。主ボタンと並べる場合は右に主、左に副。

## 6. レイアウト

### PC：右サイドパネル（モック：`previews/mock-pc-panel.png`）
- 探索キャンバスは全画面のまま、右に幅 380px のパネルを重ねる（開閉でキャンバスを縮めない）。
- 構成：左レール 64px（タブ縦並び）＋本体 316px。
- 本体スクロールは一覧だけ。詳細は一覧の上に重なる第2層（同じパネル内スライド）か、
  一覧下半分固定でもよいが、**主ボタンは常時見える位置**（本体下端に固定）。
- パネル外周は `line-strong` 1px。画面端にぴったり付ける（浮かせない）。

### スマホ：下部ナビ＋ボトムシート（モック：`previews/mock-phone-sheet.png`）
- 下部ナビ：高さ 56px＋セーフエリア、地 `bg-deep`、上端 `line` 1px。
  6タブ均等割り、アイコン 28px＋ラベル 10px。選択中はアイコン不透明度 1＋
  **上端に teal 3px の横線**＋ラベル `text`。
- 画面コンテンツはボトムシート：上端だけ角 12px、地 `panel`、
  上端中央にドラッグハンドル（幅 36px、高さ 4px、`line-strong`）。
  高さは最大 78vh、一覧はシート内スクロール、主ボタンはシート下端に固定。
- シート背面の探索画面は暗転させない（フィールドノートは「脇に開く」もの）。

## 7. アイコンの使い方（必読）

- 実表示 32〜48px には `48/` 版、24px 以下には `32/` 版、`image-rendering: pixelated`。
- アイコンは暗い地（`panel` 以下）専用設計。明るい地に置かない。
- 文字・数字をアイコン画像に焼き込まない。バッジ（未読数など）は Claude 側で重ね描き。
- 透過縁は α 二値化で締めてある（白にじみなし）。追加のドロップシャドウを付けない。

## 8. 禁止事項（コンセプトの番人）

- ネオン色・強いグロー・ガラス質グラデーションを使わない。
- 羊皮紙テクスチャや焦げ縁で「古文書」に寄せない。
- UI の都合で世界に高度な設備を置かない（UI は UI、世界の文明段階は別）。
- 絵文字をアイコンの代わりに使わない。例外扱いの増殖もしない。

## 9. Claude への申し送り

- 本仕様の色・寸法は ui.js の CSS 変数にそのまま写せる形にしてある（第1〜2章）。
- モック HTML（`mock.html`）は寸法と階層の見本。実装は既存 UI の構造に合わせてよいが、
  状態表現（第4章）と主ボタンの常時表示（第6章）は崩さないこと。
- アイコンの追加が必要になったら、勝手に描かず GPT 生成シート→仕上げの既存手順
  （`assets/ui-icons/README.md`）で増やす。
