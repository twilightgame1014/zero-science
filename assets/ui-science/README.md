# 科学系UI デザイン一式（2026-11-11 ラウンド）

「文明再建を進める科学者のフィールドノートと実験器具」をコンセプトにした
メニューUIのデザイン納品。実装は Claude 側（ui.js）。

| ファイル | 内容 |
|---|---|
| `design-spec.md` | 配色・余白・角丸・文字・状態色・タブ状態・レイアウトの正本仕様 |
| `mock.html` | PCサイドパネル／スマホ下部ナビ＋ボトムシートの寸法見本モック |
| `previews/mock-pc-panel.png` | PCモックの描画確認 |
| `previews/mock-phone-sheet.png` | スマホモックの描画確認 |

アイコンは新規作成せず、確定済みの `assets/ui-icons/`
（lab/craft/encyclopedia/journal/map/settings ＋ technology/base）を使用。
選定理由と使い方は `design-spec.md` 第3・7章。
