# ui-science（このブランチ分）

## lab-bench-bg.svg — 実験台の背景、生成り＋濃紺版（ラウンド28 / Claude §25.4c）

研究室の実験台シーン（ui.js `drawScene` / `labBackground`）の背景を、
メニューの配色（生成り #F3EEE2・濃紺 #17212C/#202D3B・青緑 #1D7F7B・
控えめな琥珀 #C38A2E）に寄せた SVG 版。

- viewBox は既存シーンと同じ `0 0 400 225`
- 座標アンカーも既存と一致: 棚板の上面 y=96、実験台の天板 y=186。
  装置・器具スプライト（ASSETS.labApp）は従来どおりこの上に重なる
- 組み込み方法（Claude 側）: `labBackground(st)` の室内ステージ
  （st>=3）の置き換え、または `<image>` として背景に敷く。
  屋外ステージ（st<3）の空・丘はこのファイルには含まない
- 中身: 生成りの壁＋濃紺の腰板、窓（青緑寄りの空）、棚の上の容器の
  輪郭、吊りランプ（琥珀はここだけ）、腰板に掛けた記録表（罫＋青緑の折れ線）

※ 科学系UIのデザイン仕様書・モック一式は
`feature/graphics-volcano-walk-ui`（ラウンド27）側の
`assets/ui-science/` にある。本ファイルはその配色に合わせてある。
