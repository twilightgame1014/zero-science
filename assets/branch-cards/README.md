# branch-cards — 枝葉カード素材（木の樹冠用）

オーナー提供の生成シート（枝葉4種、2列×2行）を加工し、樹冠を
「葉のついた枝のカード」で組み立てるための素材セット。
球体樹冠の置き換え（2026-11-07、木の見直しラウンド）で使用。

## 対応表

| ファイル | 元シート位置 | 枝の形 | 主な用途 |
|---|---|---|---|
| branch-1 | 左上 | 左下の茎から右へ広がる噴流状の枝 | 樹冠の側面・上部 |
| branch-2 | 右上 | 右上へ斜めに伸びる枝 | 樹冠の上部・斜め方向 |
| branch-3 | 左下 | 垂れ下がる枝 | 樹冠の下縁・側面下部 |
| branch-4 | 右下 | 横に広がる枝 | 樹冠の側面・中層 |
| branch-cluster | （合成） | branch-1/2/4 を重ねた葉塊 | 遠距離 LOD 用の簡略樹冠 |

## 加工内容（tools/process_branches.py、再実行可能）

- 象限ごとに切り出し（シート端・象限境界に内容は接しておらず、欠けなし）
- 白背景の除去：min(R,G,B) ≥ 243 を背景として透過。葉の間に囲まれた
  白い隙間も透過になる（隙間ポケット 5,600〜10,200 px/枚）
- ゴミ画素の除去：12 px 未満の孤立成分を除去（44〜63 個/枚）。
  枝葉本体は全枚とも単一成分として保持
- 縁のにじみ・白い斑点の除去：淡く低彩度の画素（輪郭の黄緑色の
  ハレーション＋葉上の白い斑点、約 11,700〜14,400 px/枚）を、
  最も近い内側の色で塗り直した。葉本体（黄緑、チャンネル差 ≥ 60）は不変
- 色調：最も明るい黄緑だけをわずかにオリーブ側へ寄せた
- アルファは {0, 255} の二値（描画側は alphaTest の切り抜き前提）
- 出力：`sprites/branch-N-master.png`（トリミング原寸）と
  `sprites/branch-N.png`（長辺 512 の実行時版）
- 実行時表示の確認：`previews/contact-dark.png`（暗背景の合成確認）、
  `previews/display-size.png`（ゲーム表示相当の約 150 px 幅でも
  葉の粒が潰れないことを確認）

## 描画側への渡し方

`tools/bundle_textures.py` が実行時版を WebP（q88）化して
`src/graphics/branchTextures.ts`（両ツリー）に data URI で埋め込む。
合計約 330 KB。キーは branch_1〜branch_4 / branch_cluster。

原画は `source/branch-sheet.jpg` に無加工で保管。
