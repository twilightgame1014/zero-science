# UIアイコン（GPT生成シートの仕上げ済みアセット）

元シート（`source-sheet.png`、2行×4列）を個別に切り出し、透過を整えて
実UIアセット化したもの。機械的な等分ではなく、アルファの連結成分ごとに
実バウンディングボックスを取って切り出している（生成画像は配置が均等で
ないため）。透過は元々あったが、全面に薄いヘイズ（α≈1〜250のばらつき）が
あったため、α≥128を不透明・未満を透明に二値化して輪郭を締めた。
歯車の中心穴は正しく透過している。

## ファイル対応表

| ファイル | 意味（ゲーム内） | 元シート位置 |
|---|---|---|
| `lab.png` | 研究室（実験台） | 上段1 |
| `craft.png` | 工作 | 上段2 |
| `encyclopedia.png` | 図鑑 | 上段3 |
| `technology.png` | 技術 | 上段4 |
| `journal.png` | 記録 | 下段1 |
| `map.png` | 地図 | 下段2 |
| `base.png` | 拠点 | 下段3 |
| `settings.png` | 設定 | 下段4 |
| `menu.png` | メニュー | （原画なし・仮アイコン、下記参照） |

- ルートの PNG がマスター（192×192、アイコン占有は最大168px、重心寄せ配置）
- `48/` と `32/` は実表示サイズ版（全てニアレストネイバー縮小でドット感を保持）
- CSS/canvas では `image-rendering: pixelated` を推奨

## 小サイズでの視認性（確認済み）

- 48px：8種とも明瞭
- 32px：8種ともシルエットで識別可能。`base` の看板のフラスコや `map` の
  羅針盤など極小の内部意匠は潰れる（想定内）。判別が要る場面では 48px 版を
  使うこと

## 出典

GPT生成のシートをオーナーが提供。切り出し・透過整備・整列は Muse。

## menu アイコンについて（2026-11-06 追補）

`menu.png`（＋48/32）は GPT の原画がないため、既存アイコンの色使い
（木枠・羊皮紙・金の鋲）に合わせて Muse がドット描画した仮アイコン。
「一覧が書かれた木の板」。GPT の正式版が届いたら差し替えること。
