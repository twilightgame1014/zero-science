# 研究室メイン画面 背景イラスト（発展段階セット）

科学文明再建シミュレーションゲーム 開発指示書 Ver.1.0 第9章（研究室の発展）対応の背景素材です。
すべて横長 16:9、WebP 形式。メイン画面の背景として、研究環境の段階に応じて切り替える想定です。

| ファイル | 段階 | 内容 | 対応する文明段階の目安 |
|---|---|---|---|
| lab-stage-1-primitive-workshop.webp | 第1段階：野外作業場 | 森の開拓地、木の作業台、石器、土器、石のかまど、小川 | 第1段階 原始科学 |
| lab-stage-2-early-chemistry.webp | 第2段階：初期化学の小屋 | 木造小屋、ガラス器具、簡易蒸留装置、土製の炉、鉱物・薬草の棚 | 第2段階 初期化学 |
| lab-stage-3-industrial-lab.webp | 第3段階：近代工業ラボ | レンガ＋鉄骨、蒸留塔、圧力計、精密天秤、銅コイルの発電機、配管 | 第3段階 近代工業 |

## 使い方のメモ
- 画面遷移ではなく、設備の製作・研究の進展に合わせて背景を差し替えることで「文明が発展した報酬」として見せる想定。
- 1・3・4枚目は四隅が柔らかいビネット（にじみ）になっています。UIを周囲に配置しても絵と競合しにくいです。2枚目は全面絵です。
- 人物と読める文字は入れていません。モニター内の図は抽象的な分子構造・グラフです。
- 次に追加できる素材：探索地域（森林／河川／海岸／山岳／洞窟など）の背景、アイテムアイコンセット、発見演出用のイメージ。
