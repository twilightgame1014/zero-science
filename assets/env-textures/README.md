# 環境テクスチャ（env-textures）

GPT 生成の地表シート／建材シート（各 2×2）から、タイリング可能な
ゲーム用テクスチャを切り出して整備した。既存の森林素材（GPT nature）と
表示スケール・粒度を合わせ、512px マスター＋256px モバイル版を用意。

## 素材対応表

地表シート（左上から）：

| ファイル | 内容 |
|---|---|
| `sand_beach.png` | 砂浜（貝殻の粒入り） |
| `riverbank_soil.png` | 川岸の土（層状の土肌） |
| `basalt_ground.png` | 玄武岩質の地面（黒い岩と礫） |
| `red_iron_ground.png` | 鉄分を含む赤い地面 |

建材シート（左上から）：

| ファイル | 内容 |
|---|---|
| `brick_wall.png` | 焼きレンガ |
| `plaster_wall.png` | しっくい |
| `wood_planks.png` | 木板 |
| `stone_wall.png` | 石積み（苔むした目地） |

各素材に `_normal.png`（法線）と `_256` / `_normal_256`（モバイル版）が付く。
ファイル容量の実測は `sizes.json`。

## 加工内容

- 建材シートの各区画は縦横比 2:1 のため、無理な引き伸ばしをせず
  中央の正方形を原寸密度のまま切り出した（地表は正方形区画をそのまま使用）。
- 継ぎ目は端部クロスフェードで閉じ、`previews/tiling-*.png` の
  3×3 反復表示で全素材とも継ぎ目が目立たないことを確認済み。
- 法線マップは色画像の単純なグレースケール変換ではなく、平滑化した
  高さ場から勾配を取って別途生成（タイリング対応に循環勾配を使用）。
- brick_wall は既存素材のパレットに寄せて彩度を 0.85 に軽く補正。
  それ以外の色は原画のまま。
- 注意点：basalt_ground と wood_planks は 3×3 以上の広い反復で模様の
  規則性がやや見える。実地では頂点色の濃淡・デカール併用で崩す前提
  （既存の GPT 地面タイルと同じ運用）。

## 地表同士の境界について

地表素材同士のブレンドは、テクスチャ側ではなく描画側のマスクで
行う設計（既存の地形頂点色＋デカール方式と併用可能）。本一式の
テクスチャはすべてタイリング可能なので、マスクブレンドの素材として
そのまま使える。

## Claude 向け

- 配置先：`assets/env-textures/textures/`（本フォルダ）。
- Three.js では `map` に本体、`normalMap` に `_normal` を指定し、
  `wrapS/wrapT = RepeatWrapping`。モバイル／低品質時は `_256` 版を使う。
- 地表への適用（地形の detail テクスチャ差し替えやバイオーム別ブレンド）は
  ゲーム統合側の作業。今回の納品は素材と検証プレビューまで。
