# GPT 引き継ぎ：宇宙服スプライト制作仕様（Muse → GPT）

主人公が宇宙服を着た姿のスプライトを、3D デザイン資料から
起こすための仕様。デザインの正は 3D 側（Muse）にある。

## デザイン資料（必ず参照）
- 方向別レンダー：`assets/rocket/previews/`
  suit-front / suit-back / suit-left / suit-right /
  suit-diag-front / suit-diag-back.png（点検台に装着した姿）
- 3D 本体：`assets/rocket/models/spacesuit-display.glb`
- 色：生成り #E8DFC8（スーツ地）/ 濃紺 #22364F（関節・ブーツ・
  グローブ）/ 青緑 #1D7F7B（胸部ユニット）/ 金属 #8A8D90
  （バックパック）/ 琥珀 #C38A2E（バイザー縁・小物）
- 部位の対応：ヘルメット（球形、白）＋暗いバイザー（琥珀の縁）／
  胸の青緑コントロールパック（発光ドット2つ）／背中の金属
  バックパック（白タンク2本＋青緑帯）／紺の関節・ブーツ・グローブ

## スプライト契約（既存シートと同一）
- 男女共通の標準デザイン。既存の主人公シート
  （player-spritesheet-{boy,girl}-8dir.png）と完全に同じ体格・
  足元基準で描くこと。身長・頭身を変えない。
- セル 256×256 px、可視高 200 px、足元基準線はセル下端から
  29 px、中心 x = 127.5。
- 8方向（行）× 歩行フレーム（列）。列0 は静止画。
  行の並び・列構成は既存 8dir シートと同一にする。
- 背景は完全透過。影は描かない（ゲーム側で付ける）。
  文字・ロゴは入れない。

## 生成時の指定
- ファイル名案：player-spritesheet-boy-suit-8dir.png /
  player-spritesheet-girl-suit-8dir.png（最終名は Claude と確認）
- バイザーは不透明な暗色（顔は見せない）。ヘルメットで髪は
  隠れるため、男女の差は体格の既存差のみ（新規の差別化を足さない）。
- 質感は既存シートのドット絵タッチに合わせる。3D レンダーの
  質感をそのまま写さない（資料は形と色の確認用）。
- 歩行フレームではバックパックとホース類が体から離れて
  見えないよう、シルエットは静止画と揃える。

## 納品前チェック（GPT 側）
- 全方向で足元基準線が 29 px に揃っていること
- 可視高 200 px ±2 に収まること（ヘルメット上端で測る）
- パレット外の色（特に純白・純黒のベタ塗り）を増やしていないこと
