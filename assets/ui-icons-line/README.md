# ui-icons-line — フィールドノート配色の線アイコン（ラウンド28 / Claude §25.4）

メニュー（濃紺の帯・生成りの紙・青緑＝選択中・琥珀＝実行）に合わせた
線画アイコンセット。既存の `assets/ui-icons`（色つきピクセル絵）の
置き換え候補で、ゲーム側の組み込みは Claude の作業。

## 構成
- `svg/` — SVG マスター（色違い3種: `-cream` / `-teal` / `-navy`）
- `png/24/`, `png/48/` — 書き出しPNG（透明背景）
  - ナビ・見出し用アイコンは cream / teal の2色
  - 状態印は cream / teal / navy の3色

## アイコン（24px グリッド・線幅1.7・丸キャップ）
| ファイル名 | 用途 |
|---|---|
| lab | 研究室（フラスコ。UI上の記号としてのみ使用し、原始世界の3Dには置かない） |
| craft | 工作（ハンマー） |
| encyclopedia | 図鑑（開いた本） |
| technology | 技術（ノードネットワーク） |
| journal | 記録（しおり付きノート） |
| map | 地図（折り地図＋ピン） |
| settings | 設定（歯車） |
| base | 建築／拠点（家） |

## 状態印（§25.4b・色だけに頼らない形の違いつき）
| ファイル名 | 意味 | 今の代替表現 |
|---|---|---|
| state-undiscovered | 未発見 | 点線の輪＋？ |
| state-blocked | 加工できない | 輪＋斜線 |
| state-lacking | 材料不足 | 三角＋！ |
| state-selected | 選択中 | 塗り円＋チェック（地色は使用側の配色で） |

## 色
- cream `#F3EEE2`（濃紺の帯の上）
- teal `#2FA39C`（選択中・生成りの紙の上でも読める中間色。
  厳密な指定色は template の `--teal` #1D7F7B（明）/ #3FB0AA（暗））
- navy `#17212C`（生成りの紙の上）

SVG は `stroke` のみで構成され、色はファイルごとに焼き込み済み。
色を変えたい場合は SVG 内の16進色を置換すればよい。
