# 研究室メイン画面 背景イラスト（3Dレンダリング調・推奨版）

科学文明再建シミュレーションゲーム 開発指示書 Ver.1.0 第9章（研究室の発展）対応。
水彩イラスト版（lab-stages/）へのフィードバック「AI感が強いので3D感を出したい」を受けて、
同じ構図のまま、様式化された3Dゲーム環境レンダリング調に描き直したセットです。

- すべて横長 16:9、WebP 形式、全面絵（ビネットなし）
- 質感：木・石・粘土・ガラス・金属などの素材感、体積光、浅い被写界深度
- 人物なし、読める文字なし
