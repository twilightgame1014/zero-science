# 実験器具アセット（研究室→「実験台」用）

AI生成の研究室背景画像の置き換えとして制作した、統一様式の軽量器具セット。
部屋の一枚絵ではなく、**装置ごとに分かれた素材**なので、解放済みの設備だけを
実験台の上に組み合わせて表示できる。

## 構成（3形式が同じ形状）

- `bbmodel/` — Blockbench ソース（ピクセルテクスチャ埋め込み、編集用）
- `gltf/` — glTF 2.0（ジオメトリ。テクスチャは `textures/` の同名系統 PNG を
  マテリアルの map に割り当てて使う。UV は全面マッピング）
- `sprites/` — 正面・正投影の透過 PNG（256×256）。装置本体と液体・炎は
  **別レイヤー**で、同じ原点・同じ縮尺なので重ねるだけで合成できる
- `sprites/sets/` — 合成済みの見本（装置＋液体/炎）
- `textures/` — ピクセルテクスチャ一式＋実験台の木目 `bench.png`（タイリング可）

## 装置と段階対応

| 装置 | 基本形 | レイヤー（重ね素材） | 段階 |
|---|---|---|---|
| フラスコ | `flask` | `flask_liquid`（青） | ガラス〜 |
| ビーカー | `beaker` | `beaker_liquid`（緑） | ガラス〜 |
| 試験管立て | `testtubes`（木台）＋`testtubes_glass` | `testtubes_liquid`（橙） | ガラス〜 |
| 乳鉢 | `mortar`（石） | — | 原始〜 |
| 容器（壺） | `jar`（土器） | `jar_contents`（中身）／`jar_lid`（木蓋） | 原始〜 |
| 加熱器（アルコールランプ） | `heater` | `heater_flame`（炎） | ガラス〜 |
| 火鉢 | `brazier`（土器） | `brazier_coals`（炭）／`brazier_flame`（炎） | 原始〜 |
| 電気加熱器 | `heater_modern`（金属） | — | 近代〜 |

液体の色違いは `textures/liquid_blue|green|orange.png` の差し替えで作れる
（形状は共通）。泡・湯気・発光などの演出は素材ではなく描画状態として
ゲーム側の演出（パーティクル等）で扱う前提。

## 座標・原点

Blockbench 単位（16単位＝1m）、原点は台に接する底面中心。
スプライトは全て 256×256・同一スケール（器具の実寸比を保持）。

## 出典・ライセンス

全て本プロジェクト用にコード生成したオリジナル素材（Blockbench で構築、
Blender でスプライト化）。外部素材は不使用。Poly Haven は質感の参考として
評価したが写真質感が画風と合わないため本セットには採用していない。
