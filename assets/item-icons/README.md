# 物質アイコン一式（item-icons）

『ゼロからの科学』の全アイテム用アイコン。GPT 生成シート9枚（4×4×8枚＋
3×3×1枚）と、moltenglass 差し替え用の「るつぼ」単体画像から切り出して
整備した。ゲーム本体の ID・レシピ・進行・保存仕様には一切触れていない。

## 構成

| パス | 内容 |
|---|---|
| `icons/<id>.png` | 個別アイコン 137 点（256×256 透過 PNG、ファイル名＝アイテム ID） |
| `atlas.png` / `atlas.webp` | 全アイコンのアトラス（3072×2880、セル 256px、並びは data.js の定義順） |
| `atlas-128.png` | セル 128px の軽量アトラス |
| `atlas.json` | 対応表：ID → {x, y, w, h, name（日本語名）, sheet, row, col} |
| `previews/` | 明背景／暗背景 × 64px／48px の一覧プレビュー（縁と識別性の検証用） |
| `source/` | 原画シート（無加工で保管） |
| `tools/` | 加工スクリプト（process_icons.py / build_atlas.py / build_previews.py） |
| `process-log.json` | 加工ログ（シート別フリンジ修正数、アイコン別成分数） |

容量：個別 PNG 一式 約 7.8 MB／atlas.png 約 7.4 MB／atlas.webp 約 5.1 MB／atlas-128.png 約 2.3 MB／atlas.json 約 19 KB。

## ID 照合

`src/game/data.js`（feature/game-walk-and-assets 時点）の全アイテム 137 件と
1:1 で完全一致（過不足ゼロ）を確認済み。日本語名は atlas.json に参考として
収録したが、表示名は従来どおりゲーム側の文字列を使うこと（画像への焼き込みなし）。

## Claude 向け読み込み方法

- 手軽な方法：`icons/<id>.png` をそのまま `<img>` / CSS / Canvas で使う。
- 一括読込：`atlas.webp`（または atlas.png）を読み、`atlas.json` の x/y/w/h で
  切り出す。並び順は data.js の定義順で固定。
- 表示サイズ 48〜64px での識別性は previews/ で検証済み。

## 加工内容と修正一覧

1. **moltenglass**：シート6内の瓶アイコンは使わず、指定どおり別添の
   「るつぼから粘性ガラスを持ち上げた画像」に差し替え。なお原画が斜めの
   棒を含む構図のため、外形基準の正規化では他のアイコンより少し小さく
   見える（意図的な構図として維持）。
2. **輪郭にじみ除去**：透過シート（2・5）には生成器特有の赤・黄・青の
   色にじみがあったため、アルファの霞を α≥128 で二値化し、輪郭帯の
   高彩度ピクセルを内側の色へ寄せて除去（シート2: 2,406px、シート5:
   にじみの大半は霞側にあり二値化で除去・残り 5px、るつぼ画像: 377px）。
3. **白背景シートの切り出し**：機械的な等分割ではなく、境界からの
   フラッドフィル（近白 ≥243）で背景を判定し、連結成分をセル中心で
   割り当てた。塩・白い粉・ガラス器など「白い被写体」の内側は保持。
   小石の山や貝殻など複数部品のアイコンも1アイコンに統合済み。
4. **正規化**：全アイコンを 256×256 キャンバスに、外形の長辺 208px・
   中央配置で統一。48px／64px 表示で形が読めるよう細部は原画のまま保持。
5. **あえて変えていないもの**：無色の液体（雨水・川の水・上澄み等）と
   気体（水蒸気・CO2・SO2・水素・酸素）のフラスコ群は生成原画のまま。
   区別のために不自然な色は付けていない（識別はゲーム側の名称表示で担保）。
   容器の絵は概念表現であり、実際の保管方法の説明として扱わないこと。
6. 形状・材質の誤りとして作り直しが必要なものはなかったため、上記以外の
   描き換えは行っていない。
