# 火山キット（2026-11-11 ラウンド納品）

火山エリアの景観ドレッシング一式。Blender 4.0 でモデリングし、GLB で納品。
地形そのものはモジュールの `terrainHeight`（成層火山プロファイル、同ラウンド改修）が
正本で、本キットはその上に置く「岩と植生」だけを担う。ゲームへの配置は Claude 側。

- 原点：底面中心（y=0 が地面）。向き：+Z 正面（岩類は回転自由）。
- 材質：全てフラットカラー材質（テクスチャなし）。灰・灰褐色・炭色基調、
  上面には灰かぶりの明色。石積み・レンガ目地なし。
- 配置ルール・衝突参考形状は `metadata.json` が正本。
- 生成スクリプト：`tools/build_volcano_kit.py`（Blender headless で再生成可能）。
- 検証配置はモジュール demo の `verify.html?kit=1`（アンカーは同梱カタログ準拠）。
