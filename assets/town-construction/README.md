# town-construction — 自由配置・段階建設に対応する街施設（M4-02）

オーナー指示（2026-11-14）：街・工場アセットを「自由に場所を選び、
現地へ資材を集めて段階的に建設する」方式に対応させる。
Muse はモデル・UV・材質・LOD・建設途中の表示を担当。
資材管理・建築条件・セーブ・生産は Claude。ロケット関連は対象外。

## 方式の決定

- **固定された街は作らない**：建物は1棟ごとの独立 GLB。
  周囲の地面・道路・木・隣の建物は含めない。基礎は建物自身の
  構造に必要な範囲だけ（大きな四角い土台で誤魔化さない）。
- **建設段階は「累積ノード表示方式」**：1棟 = 1 GLB。
  ノードを stage1_foundation / stage2_frame / stage3_shell /
  stage4_complete の4グループに分け、工程番号 N で
  グループ 1..N を表示する（工程0 = 予定地キットのみ）。
  座標・縮尺は全工程で同一（同じファイル内の分割なので
  ズレと二重表示が起きない）。契約 JSON に stageNodes の
  実名一覧も併記するので、階層でも名前でも制御できる。
- 予定地（杭と縄）と資材置き場の小物は建物と別モデル。
  完成モデルへ焼き込まない。

## 道路の方式

接続モジュール（板状のパーツ）ではなく、**地形に沿う連続面の
材質方式**に統一する。理由：既存の地形パス描画
（config.world.paths、火山の登山道で実績）が距離場で
塗り分けるため、直線・曲がり・T字・十字・行き止まりが
継ぎ目なしに成立し、斜面にも浮かず段差もできない。
衝突壁にもならない。パスに `kind`（dirt / gravel / stone）を
追加し、種別ごとに色・砂利の斑・縁のフェード幅を変える。
建物入口へは roadLink 点までの短いパスで接続する。
石敷きの目地パターンだけは頂点色の解像度では出ないため、
テクスチャ（512タイル可）を別途用意し、シェーダ側の
詳細テクスチャ適用を今後のモジュール課題として明記する
（今回のテクスチャはそのまま使える形で納品）。

## 配信サイズ

dist の上限 16 MB は現状ほぼ満杯（15.54 MB）。今回の GLB は
buildings-3d と同じ共有テクスチャ（planks / thatch / earth /
bark / stone / brick / metalroof / iron / plaster / tile）を
使い、ゲーム側の軽量化（tex:<hash> 共有化）で重複を消す前提。
新規テクスチャは道路3種のみ。容量の実測は README 末尾と
契約 JSON に記録する。組み込み時の増分見積もりは
Claude 向け導入手順（INTEGRATION §37）に書く。
