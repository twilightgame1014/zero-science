# buildings-3d — 設置建物13種の3Dモデル（2026-11-07、テクスチャ改修 第14ラウンド）

原画（`../buildings-icons/source/buildings-1.jpg` / `buildings-2.jpg`）を
設計図として、Blenderで実モデル化した設置建物13種。単色の箱・球の
組み合わせではなく、構造（骨組み・開口・付属設備）→輪郭→色面→質感
の順に作り込んである。

**第14ラウンド（2026-11-07）**: オーナー提供の素材原画3枚
（`source-gpt/sheet-1..3.jpg`、各2×2=12素材）を使い、全13種の外観を
改修した。手続きテクスチャは廃止し、原画由来の素材に差し替え。
UVは全面ごとに実寸スケールへ正規化し、全建物でテクスチャ密度を
統一した（下記「素材と適用先」参照）。

## 構成

- `models/<id>.glb` — ゲーム導入用GLB（原点=接地中心、1単位=1m、前面=+Z）
- `textures/*.png` — 素材テクスチャ12種×（albedo 512px / 法線 256px /
  粗さ 256px）＋補助4種（年輪・煤デカール・炎カード・接地影）。
  モデルに埋め込み済み。旧・手続きテクスチャ14種は廃止（git履歴に残存）
- `structures.json` — ID・寸法・占有形状（footprint）・入口・操作位置・
  可動部・素材メモの対応表（Claudeの組み込み用）
- `renders/<id>.png` — three.js（ゲームと同バージョン0.180）ビューアで
  ゲームの探索カメラ（pitch 32° / yaw 45°）から撮った確認画像。
  `renders/contact-sheet.png` に13種の一覧もある
- `tools/process_textures.py` — 素材加工（切り出し・タイリング化・
  法線/粗さ生成・補助テクスチャ生成）。継ぎ目検証値は
  `texture-report.json`、2×2タイリング確認画像は `previews/`
- `tools/build_buildings.py` — モデル再生成
  （`blender -b -noaudio --python tools/build_buildings.py -- models`）

## 素材と適用先（第14ラウンド）

素材原画は未加工の2×2シート。各素材を個別に切り出し（境界は内側に
寄せて隣の混入を回避）、構造素材（板材・草葺き・レンガ・瓦・金属
屋根）は模様の周期に合わせて切り抜いてタイリング化、有機素材は
端部クロスフェードで継ぎ目を消した。原画の強い陰影は平坦化し、
彩度・コントラストはキャラクターに合わせて抑制。

法線マップは**色の明暗からではなく構造から**生成：レンガ/石積みは
目地マスク、板材は板の溝、瓦は重なり、金属屋根はリブ、樹皮は縦の
隆起。木目や銅の緑青などの色むらは凹凸にしていない（銅の法線は
ほぼ平坦）。粗さは絶対値マップ（目地は粗く、銅の地金部は滑らか・
緑青部は粗い、鋳鉄は斑で変化）。

| 素材 | 主な適用先 |
|---|---|
| 板材 planks（木目=部材長手方向に2向き用意） | 作業台の天板・棚、水車の羽根板・導水板、研究室の実験台、工場の扉・木箱、やぐらの床・小屋 |
| 草葺き thatch | 小屋の屋根（棟→軒の流れ＋軒先の房飾り） |
| 土壁 earth | 小屋の壁 |
| 樹皮 bark | 丸太部材全般（脚・柱・支柱・車軸）。切断面は年輪テクスチャを別途適用 |
| 自然石 stone | 土台・基礎・炉の基部（広い面用 stone 大タイル／薄い面用 stone オフセット版も用意） |
| 焼き土 clay | 窯のドーム（横線なし）、製錬炉の炉体 |
| レンガ brick（実寸スケール） | 工場の壁・煙突、発電所のボイラー棟・煙突 |
| 瓦 tile | 研究室の屋根 |
| 鋳鉄 iron（斑・明度調整済み） | 蒸気機関のボイラー・台枠・フライホイール、精留塔の足場・梯子、工場の窓枠 |
| 銅 copper（緑青は局所） | 精留塔の凝縮器・配管、蒸気機関の配管、研究室の蒸留ポット、変圧器のブッシング |
| 金属屋根 metalroof（リブ方向2種） | 工場の鋸屋根、発電所のアーチ屋根、研究所の屋根、小屋根・庇 |
| 漆喰 plaster | 研究室の壁、研究所の外壁、発電所のホール壁 |

建物ごとの変更点（形状修正）:
- たき火: 三角形の炎→十字の炎カード（輪郭の揺らぎ＋発光グラデ）＋
  小さな芯コーン。熾火の粒・灰床・薪（樹皮＋年輪の切断面）を分離
- 窯: 焚き口を石枠＋実奥行きのある暗い空洞に再構成し、発光は内部の
  低位置のみ。煤は口周辺だけにデカールで局所配置
- 小屋: 軒先に不揃いな草の房を追加
- 製錬炉: 炉口に空洞＋小さな内部発光を追加
- 窓: 白い発光板→枠＋暗いガラスが基本。光る窓は工場1枚・研究所の
  フラスコ1点・発電所の丸窓だけに限定
- 全建物: 接地に柔らかい放射グラデーションの影（`ContactShadow`
  ノード）を追加。四角い地面絵の焼き込みではない。地形と干渉する
  場合はこのノードだけ外せる
- 水車: 橋脚の下部だけ濡れ石（暗色・低粗さ）に。回転する車輪側は
  濡れ表現を付けていない（回転で不自然になるため）

GLB合計は約24.6MB（1体あたり0.5〜2.8MB）。テクスチャ埋め込みのため
第13ラウンド比で増えている。軽量化が必要な場合は、法線/粗さを
落とすか albedo 256px 版の再生成（`process_textures.py` の SIZE）を
検討すること。

## 原画からの判断

- **水車**: 原画は水車小屋付きだが、既存仕様の水車は動力設備単体。
  付属建屋は参考扱いとし、小屋は追加していない（水車+脚台+導水板のみ）。
- **発電所**: 原画どおり火力型（タービン建屋+ボイラー棟+変圧器+煙突）で
  造形。**オーナー決定（2026-11-07）: 火力のまま、段階建物（新設
  コンテンツ）として扱う。** 現行設定の発電は水力発電機 generator の
  みのため、設定上の整合は Claude/GPT 側で確認・決定する。
- **蒸気機関**: 据え置き型（水平ボイラー+ピストン+フライホイール）。
  機関車にはしていない。**精留塔**は電波塔状の部品なし。**水車**は観覧車に
  していない（羽根板・軸・支持構造あり）。
- 炎・発光部はモデル本体と分離（Flameノード／発光マテリアル）。煙は
  モデルに含めず、従来どおりエフェクト側（playVisualEffect 'smoke'）。

## 組み込み方法（Claude向け）

現行の `StructureRenderer` はファクトリ差し替え式で、ヘッダーコメント
どおり GLB 読み込みのファクトリを `registerFactory` で登録すれば
呼び出し側は無変更で置き換わる。GLBの配信方法（単一ファイルビルドへの
同梱か、assets 配信か）はゲーム側の構成に合わせること。寸法・占有・
入口・操作位置は第13ラウンドから不変（炎カード化でたき火の高さのみ
0.75→0.83、水車と小屋は装飾分 +0.02）。

## 検証範囲

- three.js（ゲームと同バージョン 0.180）のビューアで、ゲームの探索
  カメラ（pitch 32° / yaw 45°）から全13種を確認（renders/）。
  第13ラウンドのGLBも同じビューア・同じ画角で撮り直し、前後比較を
  揃えた。可動部（Wheel / Piston / DrillPipe / Winch）の回転・移動も
  再確認済み（変形後のフレーム差分で計測）。
- スマホ相当サイズ（220px表示）でも全13種の判読性を確認済み。
- テクスチャの継ぎ目：有機素材は継ぎ目指標 ≒1.0（継ぎ目なしと同等）。
  構造素材は周期切り抜きで目視確認済み（`previews/tiling-*.png`）。
  高コントラスト模様では指標が大きめに出るため目視を正とした。
- 残課題: 窯ドームは球面UVのため、土の渦巻き模様が緩い帯状に見える
  （レンガ状の横線ではない）。気になる場合はドーム専用の
  テクスチャ再生成が別途必要。
- Blender の EEVEE レンダーはこの VM に libEGL がなく未実施 —
  代替として実エンジン（three.js）での確認を優先した。
- 実ゲーム内での配置確認・実機 FPS は未実施（Claudeの組み込み後）。
