# レシピ図鑑のスキーマ（2026-11-14、Claude。ロードマップ M2-01・M2-03・M1 の入手経路）

図鑑の 1 項目は `BOOK.entry(S, id)`（`src/game/book.js`）が、正本のデータからその場で組み立てる。レシピ・数量・設備の条件を図鑑用に書き写さない（二重管理しない）。

## 項目の欄と正本
| 欄 | 中身 | 正本（どこから読むか） | 状態 |
|---|---|---|---|
| `id` | 既存の安定したアイテム ID | `data.js` の `items`（変えない） | 実装済み |
| `name`・`yomi`・`en` | 名称・読み・英名 | `items` | 実装済み |
| `cat`・`catName` | 分類：設備・道具・鉱石・天然の素材・製品・材料（操作は別の一覧） | `book-data.js` の `cats`（品目のタグから決める） | 実装済み |
| `kid` | 短くやさしい説明 | `items[].kid` | 実装済み（全件） |
| `nature` | 自然界での存在形態 | `items[].nature` | 天然の原料 40 種はあり。ほかは「自然の中にはそのままの形ではほとんどない」と表示 |
| `obtain` | ゲーム内の入手方法：採集（地域・道具はどれか 1 つ）・珍しい発見・研究室（操作・設備はどれか 1 つ・道具）・工作・宇宙計画の製作（秒数・実習）・現地に建てる（資材の合計・工程・施工の秒数）。材料と数量・生成物と数量（副産物を含む）・設備・道具・時間 | `regions`・`procs`・`crafts`（`space:true` を含む）・`construction-data.js` | 実装済み |

## 閲覧の決まり
- 発見のきまりは `E.status` のまま。
  - 未発見の物は「？？？」で分類だけを出す。名前・読みでは探せない。
  - 逆引きの中の未発見の物も「？？？」。
- 学習用の「全部を見る」（`S.flags.bookAll`）は閲覧の設定だけで、発見・持ち物・解放は変えない。セーブは v6 のまま。

## 設備の判定
- 設備が使えるかは `E.hasTool`。
- 建設の決まり（新しいゲーム・v5 からの移行）では、建物の設備は**完成した建物があるときだけ**使える。持ち物にあるだけ・予定地・施工中は使えない。
  - 2026-11-14 に `engine.js` の `hasFacility` をこの決まりにそろえた。
  - 以前は、移行で持ち物に残った設備が建物なしで使えていた。持ち物の設備は、建築の画面の「置く」で資材なしの完成した建物になる。

## 原料までの逆引き（`BOOK.expand`・`BOOK.totals`）
- 作る数 `need` と、ノードごとの製法の選択（`choice[id]`）を受け取る。
- 回数は、1 回の出来上がりの数で割って切り上げる（余りを示す）。材料は「回数×数量」。
- 副産物も回数分を示す。
- 道具・設備は使ってもなくならないので数えない。使えるか（完成した建物か）は示す。
- 「在庫を引いた残りだけ作る」を選べる。
- 同じ物が自分の材料をたどった先にもう一度出たら「循環」で止める。深さの上限は 12。
- 製法を選ぶと、その製法での必要量になる（画面に「選んだ製法での必要量」と書く）。

## 点検（`BOOK.audit`・`BOOK.gaps`、`node scripts/export-book-ledger.mjs`）
- **`RESOURCE-LEDGER.md`**：
  - 天然の原料（採集地域・必要な道具・原料の処理・使い道・含む元素）
  - 到達不能の品目
  - 元素の出どころ：元素は地面に置かず、鉱石・水・空気・植物などの原料に含まれる物として表す
  - 説明との不一致
- **`MANUSCRIPT-GAPS.md`**：欄ごとの原稿・出典・監修の不足。
- **`book-ledger.json`**：機械で読む形。
