# 科学文明再建ゲーム — Three.js HD-2D グラフィックモジュール

Claude が担当するゲーム本体に組み込むための、**描画専用**グラフィックモジュールです。
ゲームロジック（状態・採集・反応・研究・建築・セーブ）は一切含みません。

## 内容

- Three.js + TypeScript による HD-2D 描画（正投影カメラ、約50°俯瞰）
- 手続き生成の 3D 自然フィールド：森林・川（アニメーション水面シェーダー）・岩場・草原＋建築用平坦地
- 風で揺れる草木、水の流れ、漂う光の粒子、時刻で変わる太陽光と影
- 2D スプライトキャラクター（主人公2名分の正式シート同梱、4方向歩行・待機アニメ、足元影、地形接地、実行中切替対応）
- 資源ノード表示（採取済みバリアント対応）、建築物表示（10種の仮モデル＋差し替え可能な設計）
- PC・スマホ対応：レスポンシブな表示範囲調整、品質自動判定（影解像度・描画負荷）

## デモの起動

```bash
npm install
npm run dev        # http://127.0.0.1:5173
```

デモは描画確認専用です。WASD/矢印キーの移動ドライバと仮データは `demo/` 内に閉じており、正式な入力・ゲームシステムとは無関係です。

ビルド確認：`npm run build`（型チェック＋デモのバンドル）
