# Claudeへの実装指示（そのまま渡せます）

科学文明再建ゲーム『ゼロからの科学 ～石と水と木から～』の探索ホーム化を実装してください。
リポジトリ：twilightgame1014/science-civilization-game

最初に最新main、CLAUDE.md、docs/handoff/EXPLORATION-HOME-2026-11-06.md、docs/handoff/INTEGRATION.md、src/graphics/types.tsを読んでください。今回は探索ホーム仕様が、旧HANDOFFの研究室メイン画面方針に優先します。

あなたの担当はゲーム本体・UI・入力・セーブと統合です。Museが描画担当なのでsrc/graphicsと原本素材は変更しないでください。仕様説明で終わらず実装・検証まで進めてください。

最優先：
- 探索を起動時のメイン画面にし、下部タブから研究室・工作・図鑑・技術・記録のパネルを開く。
- フィールドのDOMとWebGLインスタンスを保ち、パネルを閉じると同じ場所へ戻す。
- U.tabの初期値だけの変更では不足。setTab/render/in3D、キー・スティック・採取処理、探索更新、目標リンク、「もう一度」、モーダルまで整合させる。
- パネルや案内が開いている間はフィールドへの入力を止め、押下状態と移動予約を解除する。フォーカスとEscapeも整備する。
- 主人公が小さすぎない表示領域を確保。スマホの下部タブ・採取ボタン・スティック・セーフエリアを分離する。
- 既存の研究室背景と全機能、2Dフォールバック、既存セーブ互換を維持する。
- Museが俯角32度・viewSize16を起点にカメラを調整する。これらは調整目安であり、旧50度/26を初期化側で固定して上書きしない。
- カメラ変更後のscreenToGroundと投影表示を、高低差のある地形で検証する。公開API追加が必要なら契約を記述し、Muse側の未実装APIを無条件で呼ばない。

探索ホームUI、入力保護、描画統合の順で小さなコミットに分ける。最新差分を尊重して作業ブランチで実装する。
npm test/typecheck/build/e2eと、実WebGLでのPC・スマホ幅の確認を行う。完成条件は共通仕様を参照。
終了時はコミット、変更ファイル、検証結果、画面比較、Muse側の依存・残課題を報告してください。実装・検証していない点を完了と記載しないでください。
