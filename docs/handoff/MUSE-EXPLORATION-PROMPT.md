科学文明再建ゲーム『ゼロからの科学 ～石と水と木から～』の探索画面を改善してください。
リポジトリ：twilightgame1014/science-civilization-game

最初に最新main、docs/handoff/EXPLORATION-HOME-2026-11-06.md、docs/handoff/INTEGRATION.md、src/graphics/types.tsとreferences/exploration-camera/README.mdを確認してください。参考画像本体は未登録のため、ユーザーから別途受け取った場合に参照してください。
あなたはグラフィック担当です。ゲーム本体・UI・採取判定・セーブはClaudeが担当します。CLAUDE.mdの描画変更禁止はClaudeとの分担規則です。あなたは本体で使うsrc/graphicsを担当し、原本threejs-hd2d-graphics/だけを変更することのないよう注意してください。

ユーザーの最優先要望：
現在の画面は上から見下ろしすぎ。参考画像のように角度を下げてプレイできるようにする。探索を作り込み、主人公をもっと近く、見やすくする。

実装事項：
1. 正投影の俯角50度をまず32度へ（調整28〜36度）。viewSize26をまず16へ（調整14〜18）。yaw45度、followDamping5.5は起点として維持。数値は画像から実測したものではない。
2. 正投影なので距離90を縮めるだけでは拡大されない。frustumと縦画面補正を調整し、透明余白を除く主人公の画面上の大きさで判断する。
3. 主人公の顔・身体、建物の正面、崖の側面、道と川の奥行きが見える構図にする。キャラは足元接地・ビルボード・向き・歩行コマを保つ。
4. 低視点で木・屋根が主人公を隠す問題を遮蔽フェード等で解消。共有マテリアルを不用意に変更しない。解除時の復帰、透明描画順、影も確認する。
5. 地形端の空白や裏側を見せず、遠景・霧・地形の段差で奥行きを作る。新たな通行判定やゲーム座標の書換えを追加しない。
6. 草・土・岩・岸・木を読み分けられる密度・質感に。採取ノードと移動経路は鮮明にし、被写界深度・ブルームでぼかしすぎない。
7. PC・スマホ縦横で見え方を検証し、描画の軽量設定でもカメラの意図を維持する。
8. 必要なAPI追加は後方互換を保ち、types.tsとINTEGRATION.mdへ具体例と所有権を記す。現在存在しないAPIを既存扱いしない。
9. テクスチャの新規生成が必要ならGPTへ渡す素材仕様（用途・寸法・透過・視点・タイリング・枚数）を提出する。まず既存素材でカメラを成立させる。参考画像は鑑賞・構図参考専用で素材として切り出さない。

専用ブランチで実装し、Claude担当ファイルを上書きしない。
共通仕様の完了判定を満たし、npm run typecheck/build、npm testと実WebGLの比較画像を提出する。描画デモだけでなく本体への統合確認が必要であることを明記する。
納品時は変更ファイル、確定カメラ値、PCとスマホ縦横の画面、遮蔽対策、性能確認条件、Claudeへ渡す統合手順と未確認事項を報告してください。
