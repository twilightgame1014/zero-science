# 宇宙計画：モデル契約（Claude → Muse、2026-11-13）

最終目標「自分で作ったロケットで宇宙へ」のための 3D モデルの依頼です。
ゲームは今、**仮モデル**（`src/world/spaceModels.ts` のかんたんな立体）で最後まで遊べます。正式なモデルが届いたら、同じ種類名（`space-*`）で差し替えます。
アイテム ID・セーブ（`S.build`・`S.space`）・当たり判定はゲーム側にあり、モデルを替えても変わりません。

## 共通の決まり
- 単位：1 = 1 マス（主人公の身長は約 1.5）。Y 上、右手系。**原点＝地面の上の設置の中心**（底面の中心、Y=0 が地面）。
- 正面：**+Z**（既存の建物の GLB と同じ。入口・操作する場所が +Z 側）。
- 形式：GLB（既存の `assets/buildings-3d` と同じ流儀。接地影 `ContactShadow` ノードを入れてよい）。
- 材質スロット（名前を固定）：`Concrete`・`Steel`・`PaintedSteel`（赤さび色）・`Alloy`（軽合金・白）・`HeatTile`（暗い灰）・`Glass`・`Accent`（だいだい）・`Emissive`（表示・ランプ）。
- LOD：LOD0（〜30マス）と LOD1（30マスより遠く）。**LOD1 は LOD0 と外形・寸法を同じに**（木の LOD1 のように形が変わると、切り替えで飛ぶため使えません）。
- 占有形状（下の表）はゲームの当たり判定です。屋根・アンテナ・通路・炎は含めません。モデルの壁はこの形から 0.2 以上はみ出さないでください。
- 開始時の景観には置きません（プレイヤーが作って置いたときだけ出ます）。

## 機体（組立の段階）
機体は発射台の中心に立ちます。**原点は発射台の地面の中心**、機体の本体は `SpaceRocketBody`（位置 Y=0.5）の下にまとめてください（打ち上げ演出で、ゲームがこのノードの `position.y` を上げます）。
全高 10.2（発射台の上面から 9.8）、胴の半径 0.85〜0.9。

取りつけた部分だけを表示します。ゲームは「見える4つの部分」のビットで種類名を決めます：`space-rocket-<code>`（code = 1:機体構造 + 2:推進モジュール + 4:搭乗カプセル + 8:外装。1〜15）。
納品は **1つの GLB に4つのノード**（`Part_Frame`・`Part_Engine`・`Part_Capsule`・`Part_Skin`）でかまいません。ゲーム側で code に合わせて表示を切り替えて登録します。

| ノード | 部分 | 位置の目安（本体のローカル Y） | 備考 |
|---|---|---|---|
| `Part_Frame` | 機体構造（骨組み） | 1.6〜7.8 | 外装がないときは中が見える骨組み |
| `Part_Engine` | 推進モジュール（**架空の形**） | 0.3〜5.2 | タンク2つ＋ラッパ形のノズル。現実の機種に似せない |
| `Part_Capsule` | 搭乗カプセル | 7.9〜9.4 | 窓 1つ |
| `Part_Skin` | 外装 | 1.15〜9.8 | 白い胴・暗い耐熱の帯・だいだいの先たんと3枚の小さな翼 |
| `SpaceFlame` | 噴射 | 本体の下（Y=-1.5 を中心、長さ 3.4） | 既定は非表示。ゲームが演出のときだけ表示し、`scale` をゆらします |

内部の部分（電源・船内コンピューター・通信機器・生命維持装置）は外から見えないので、モデルは不要です（取りつけの演出はエフェクトだけ）。

## 宇宙服（主人公の装備表示）
- いまは仮の印（頭の透明な球＝ヘルメットと首の輪）を、男女どちらの主人公の絵にも重ねています。主人公の選択（`S.flags.hero`）は変わりません。
- 正式版の希望：**8方向の歩行シート（4列×8行、既存の主人公と同じ寸法・足もとの基準）を、男の子・女の子それぞれ宇宙服姿で**。シート名 `hero-boy-suit-8dir`／`hero-girl-suit-8dir`。ゲームは `S.space.wear` のときだけこのシートへ切り替えます（切り替えの口は `setPlayerSpriteSheet`）。
- ヘルメットのバイザーは顔が見える半透明、背中に生命維持ユニット（箱）。

## アニメーション・演出（ゲーム側の進行）
1. カウントダウン 10→1（後半で `SpaceArm` が縮む）
2. 噴射開始（`SpaceFlame` 表示・発射台に `smoke`）
3. 上昇（`SpaceRocketBody.position.y` を 0→約26 へ）
4. ここから先は画面全体の絵（空の色→星→地球の丸み）に切り替えます。3D の無限の上昇は不要です。

ほしいエフェクト（任意。`playVisualEffect` の種類）：`launch-smoke`（発射台から横へ広がる煙）、`ignite`（噴射の光）。なければ既存の `smoke` を使います。
