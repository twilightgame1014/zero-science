## 1. 容量（実測）
| | 生の合計 | gzip -9 | 埋め込み時（base64、約 1.34 倍） |
|---|---|---|---|
| LOD0（16 点） | 4.82MB | 1.64MB | 約 2.2MB |
| LOD1（16 点） | 1.86MB | 0.50MB | 約 0.68MB |

今の `dist/index.html` は 15.36MB（回収ラウンドを統合した `feature/game-muse-recovery-20261115`）。上限は 16MiB＝16.78MB なので、**残りは約 1.4MB**。

- LOD0 を全部入れると上限を超える。
- **LOD1 だけなら全 16 点でも約 0.68MB で入る**（残り約 0.7MB）。
- 提案は次の 2 つ：
  - 1 ファイルの版には LOD1 だけを入れる（宇宙計画の LOD0 を同梱しないのと同じ考え方）。
  - LOD0 は、配信を複数ファイルにするか、軽量化の処理（量子化・meshopt など）が決まってから。
- 置き換える旧い木のモデル（環境セットの広葉樹 6・針葉樹 2）をビルドから外せば、その分も空く（量は未計測）。

## 2. 採取との対応（提案）
### 段階 P1：見た目だけの差し替え（データ・セーブ・ID の変更なし）
| 植物 | 対応する今の自然物 | 状態 |
|---|---|---|
| 広葉樹 a/b | `tree`（variant なし） | `state_standing`＝残量あり、`state_stump`＝切った後（今の `after:"stump"`） |
| 松 a/b | `tree:conifer` | 同上 |
| 葦 a/b | `grass:reed` | `state_full`／`state_cut`（今の `after:"cut"`） |

- 採れる物（丸太・草）・量・再生（木 30 分・草 3 分）・当たり判定・ID は今のまま。
- 今の `installNatureModels`（`src/world/natureModels.ts`）と同じ包み方で、旧い GLB の代わりに使う。

### 段階 P2：新しい植物（ゲームの決まりが要る）
コウゾ・亜麻・綿・菜種・竹は、今の採取の種類にも品目にもない。

参考：今は次のとおり。
- 植物の糸：つる 2 から
- 紙：パルプから
- 油：ツバキの実から

P2 を入れるには次を決める必要がある（GPT＝ゲームディレクターとオーナーの判断）：
1. **新しい品目を作るか、既存の品目の別の採れ場所にするか。**
   - 例：亜麻・綿 → 植物の糸の新しい作り方、菜種 → 油の新しい作り方、コウゾ → パルプ、竹 → 新しい素材「竹」。
   - 新しい品目には次がすべて要る（`npm test` で検査）：
     - `kid`・`more`・`why`・`how`
     - 元素保存
     - 自然から作れる経路
     - アイテム ID の固定
   - 科学の説明は出典を作らずに「未確認」で出す。
2. 採れる量・回数・再生時間・必要な道具。
3. 置く場所（例：亜麻・綿・菜種は草原、竹・コウゾは森の縁、葦は川岸）と密度。
   - 新しい自然物は第3層の後ろへ別の乱数で足す。既存の第1〜3層の位置・ID を変えない（既存セーブの採取状態を守る）。
4. 花・実（`parts_fruit`）の有無を、季節で変えるか・採れる状態で変えるか。

## 3. 風
- 契約の値（根元を固定、最大 1.0〜3.5°、0.45〜1.1Hz、軸は `crownBase`／`culmMid`／`base`）を使う。
- 実装はゲーム側の `natureModels.ts` で行う：近くの植物のノードの回転をフレームごとに少し揺らす。描画モジュール（`src/graphics`）は変えない。
- 遠くの物は止める。採取中のゆれ（モジュールの仕組み）とは重ねない。

## 4. 建物・道の上に再出現させない
- **この仕組みはもうある。** 自然物は次の間 `state:"gone"` になり、描かれず採れない（`nature.js` の `covered`・`roadCovered`）：
  - 建物の下にある間
  - 完成した道の格子の上にある間
- 植物を自然物の見た目として入れれば、そのまま効く。
- P2 の新しい自然物も同じ判定を通す。

## 5. 当たり判定
契約の推奨値を使う。
- 木：幹だけ（広葉樹 0.34・松とコウゾ 0.28）。今の `tree` の r 0.34 と同じか小さい。
- 竹：群生の中心 0.5。
- 葦：0.35。今の草むらは通れる（`block:false`）ので、P1 でも通れるまま。
- 草本：0（通れる）。
