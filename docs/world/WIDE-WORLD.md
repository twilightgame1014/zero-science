- 「陸地」：改修前は本流の水面（川の帯の中で水位より低い所）を除いた面積。改修後はそれに加えて、深い水（海・湖・池・滝つぼで深さ 0.55 超）と崖（傾き 0.85 超）も除いた面積。海で外形を埋めていない（外形 118,336 m² のうち陸地は 90%）。

## 3. 滝が壊れていた原因と作り直し
### 原因（変更前の画像 `img/compare-waterfall.jpg` 左列）
1. 川とつながっていない：上の池・下の池が円盤（`CircleGeometry`）で、地形と別の高さに浮いている（上の池は岩の上）。上流・下流の流れがない。
2. 落ちる水は1枚の平面（`PlaneGeometry`、両面描画・深度を書かない）。厚み・落ち口の曲がりがなく、縁がまっすぐ。
3. 崖がない：地形はなだらかな斜面のまま、多面体の岩を並べて隠しているだけ（岩どうし・岩と円盤が交差）。
4. 霧（Sprite）が後処理の bloom で白く光り、横から見ると大きな白い塊になる。
5. 滝つぼの円盤は地面の高さを見ないので、斜面では片側が浮き、片側が埋まる。
6. 場所は旧世界の高地 (26.5,-15.5) で、まわりに川がない（ここを直すには旧世界の地形を変える必要があり、既存のセーブを守れない）。

→ 色や透明度の調整ではなく、地形（崖・滝つぼ・川床）から作り直した。旧い滝はモジュールのシーンで非表示（`Waterfall`）。

### 作り直した構成（`src/world/shape.ts`・`src/world/render.ts`）
1. **上流の水面**：山の池（16.4）から落ち口（13.0）まで、水面は道のりで下がる。川底は水面の下 0.4、岸は水面の上 0.28（川が浮かない・埋まらない：テスト）。
2. **落ち口**：上流の水面の帯は落ち口まで続き、最後の 1m で落ちる水の形へ引き継ぐ（同じ幅・同じ位置。すき間なし）。落ちる水は放物線で縁を越えて曲がる。
3. **落ちる水**：断面（横10分割）×道のりで掃いた閉じた薄い形（前・後ろ・左右の縁。片面描画）。厚み 0.05→0.37、真ん中が少しふくらむ、幅は少しずつ広がり揺らぐ。流れの模様は道のりに沿って上から下へだけ動く。横の縁は流れと一緒に動くでこぼこで削る（四角い縁を見せない）。光は太陽の向きで明暗。
4. **滝つぼ**：崖の下の側だけの水面（岸は円にしない）。落下点（放物線の終わり）のまわりだけに泡・波紋・しぶき（56粒、落下点から上がって落ちる）。落ちる水は滝つぼの水面の下で消えていく。
5. **下流**：滝つぼの出口までは滝つぼと同じ水面、そこから海へ下がる（水の高さは逆転しない：テスト）。出口で滝つぼの水面と川の帯が 0.6m 重なって入れ替わる（段差なし）。河口で海と重なる所は川を薄くする。
6. 移動：崖の面と滝つぼの深い所は歩けない（見た目と一致）。崖の外側のジグザグの道で上と下を往復できる。滝つぼから落ち口の上へのタップ移動は道を回る（直進しない：e2e）。

## 4. 主な実装（変更したファイル）
- `src/world/shape.ts`（新規）：地形・水・歩ける範囲・地名・地方の性格の正本。
- `src/world/terrain-shim.ts`・`scripts/world-plugin.mjs`（新規）：モジュール内の `./utils` だけを差し替えるビルドの仕組み。
- `src/world/render.ts`（新規）：外側の地形の区画（30m・細かさ4段：0.714/1.43/3/7.5m、低品質は 1.0/2.0/3.75/7.5m・端にすそ・少しずつ作る・足もとの区画は粗ければその場で作る）、海・湖・山の池・滝つぼ・山の川・本流の続き・滝・しぶき。
- `src/terrain-entry.ts`・`src/graphics-entry.ts`・`scripts/build.mjs`：入口と埋め込み（濡れた砂・雪の地面の模様。GPT 拡張素材から軽量版）。
- `src/game/nature.js`：歩ける範囲、崖・深い水（16マスの区画ごとに一度だけ計算）、経路探索（範囲を区切る）、第3層の自然物（32マスの区画ごと・順番に依らず同じ位置とID）、置き場所の判定に水・崖。
- `src/game/engine.js`：セーブ v4（`worldVer`）。
- `src/game/ui.js`：外側の描画の開始と毎フレームの更新、タップ地点（旧世界の外は地形関数で）、地名、世界の地図、拠点へ瞬間移動、斜面でのカメラの角度の一時調整、セーブの地形の版の移行。
- `src/template.html`：地図の見た目。
- テスト：`tests/world.test.mjs`（新規 42件）、`tests/nature.test.mjs`・`tests/assets.test.mjs`（広い世界の関数を渡す）、`tests/e2e/play.mjs`（広い世界の確認 7件・角の壁の位置）。

## 6. 未対応・未検証・Muse への依頼
- **未検証**：実機（スマホ・PC の GPU）での見た目と FPS、iPhone Safari、実機でのメモリの推移。SwiftShader は遅いので、区画が細かくなるまでの時間は実機より長い（撮影は確認用の `prebuild` で区画を作り終えてから）。
- 細かさの粗い区画が見えている間（遠景・読み込み直後）は、海岸線や川岸が粗い三角形のギザギザに見える。近くの区画は 0.714m（旧世界と同じ間隔）。
- 川岸・池の岸の水面の縁は、地形の三角形（0.714m）との交差の線なので、近距離では細かなギザギザが見える。
- 新しい陸地の自然物の見た目：ラウンド18の `branch:driftwood`・`grass:dry` は、モジュールが対応するまで普通の落ち枝・草むらの姿（素材は流木→木の枝、浜の草→草、貝殻→貝殻。新しい素材名は作っていない）。
- 雪：山の頂付近（高さ31〜）の平らな所だけ雪の色。雪山エリア（ラウンド18）は未統合。
- エリアごとの照明・空・霧・粒子、環境音は未実装（ラウンド18・ゲーム側の残り）。
- **Muse への依頼**（`docs/handoff/CLAUDE-TO-MUSE-2026-11-06.md` §18）：`decor.waterfall`・`decor.backdrop` の切り替え、地形の高さ関数を外から渡す公開の口、ラウンド18の7エリアの配置とのすり合わせ、本流の帯を区画読み込みで続ける、滝のしぶき・霧の見本。
