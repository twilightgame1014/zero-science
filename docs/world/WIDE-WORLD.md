## 3. 滝（原因と作り直しは前の版から変わらない）
- 旧い滝（モジュールの `Waterfall`）が壊れていた原因：川につながらない浮いた円盤の池、1枚の平面の落ちる水、崖がない、霧の白い光、斜面で浮く・埋まる円盤。→ 非表示にして、地形（崖・滝つぼ・川床）から作り直した。
- 構成：山の池 → 上流の水面 → 落ち口（水面が縁で下へ曲がる。すき間なし）→ 落ちる水（閉じた薄い形・片面描画・流れは上から下）→ 滝つぼ（落下点のまわりだけ泡・しぶき56粒・波紋）→ 下流 → 湖（湖の手前で川の帯が薄くなり、モジュールの湖の水面へ引き継ぐ）。
- 水の高さは逆転しない・川は浮かない（テスト）。崖の面と滝つぼの深い所は歩けない。

## 4. 統合で直したこと・調整したこと
- **旧世界の低地が水になる**：ラウンド18の全面の水面（`OpenWater`、760×760・水位0.32）は、旧世界の中の水位より低い乾いた低地（約5,400 m²＝旧世界の陸地の46%、深さ最大2.6）も水として描く。
  ゲームではそこは以前どおり歩ける地面（木や草もある）なので、ゲームがモジュールの全面の水面の「深さ」を旧世界の中だけ0にして見せない（本流の帯のまわりはそのまま。ソースは変更していない）。Muse に依頼（§19）。
- **画面が黒くなる**：ゲーム側の水の形（下流の川）の描き方で、範囲外の値が後処理（bloom・ぼかし）へ渡り、角度によって画面の大部分が黒くなった。ゲームのシェーダーで、逆向きの smoothstep をやめ、色と不透明度を 0〜1 に収め、正規化を守った（後処理を切ると直ることで原因を確かめた）。
- **NPC**：Muse の `setNpcVisualState` に切り替え（遮蔽フェードが効く）。絵（spriteUrl）は出したときに一度だけ渡す（毎フレーム渡すとモジュールが毎回貼り直し、SwiftShader では止まるほど重くなった）。
- **建築の候補**：Muse の `setStructurePreview`（半透明・緑／赤・影なし）に切り替え。ない版は従来どおり。
- **エリアの環境**：0.5秒ごとに `setEnvironment({weights: areaWeights(主人公の位置)})`。
- **ワープ後の地面**：モジュールの区画は「12m 動いたとき・1回に2区画」しか作らないので、瞬間移動のあとは `W3.world.afterWarp` がモジュールの区画作りを数回まとめて呼ぶ。
- 遠景の山（`BackdropMountains`）はラウンド18で外側（距離262以上）へ移ったので、表示に戻した。

### 4.1 ラウンド22（2026-11-08）
- **開水面プレーンは切らない**：Muse は `decor.openWater:false` を必須として依頼したが、その検証は統合前の世界で行われていた。統合後の世界では湖畔の湖・海・オアシスの水面はこのプレーンだけが描く。実WebGL で切ると3つとも消えることを確かめたので、切らずに、旧世界の低地の深さを0にする処理（上）を続ける（Muse への回答：handoff §20.1）。
- 地形の高さの公開口 `config.world.heightAt` に `worldHeight` を渡す。ビルドの差し替え（terrain-shim）は残す：モジュールの `EnvironmentRenderer` がまだ `terrainHeight` を直接呼ぶため（handoff §20.2）。
- 旧い滝は `decor.waterfall:false` で描かせない。瞬間移動のあとはモジュールの `prepareTerrainAt`（ない版は従来の区画作り）。

## 7. 外の野（2026-11-10、試験範囲。`feature/game-integration-20261110`）
**有限の試験範囲。地平線の先まで進める自動生成の世界ではない。**
- 歩ける範囲：長方形 ±172（`WALK`、以前どおり）に加えて、中心から半径 250（`WALK_R`）の円の中。長方形の中の地形・水・自然物の位置と ID は変わらない（`tests/world.test.mjs` で検査）。
- 地形：`worldHeight` はもとから座標だけで決まる（±180 の外はモジュールの元の地形の続き。北・南・西は起伏のある野、東は海の先に陸）。高さの式は変えていない。
- 描画：モジュールの地形の区画は ±180（60マス×6×6）まで。その外は `src/world/render.ts` がモジュールの `TerrainRenderer.buildChunk`（非公開。同じ材質・高さ・法線）で同じ大きさの区画を作り、
  近い順に1コマ2つまで（瞬間移動の直後は12まで）作り、遠くなったら捨てる（モジュールと同じ近い／遠いの2段の細かさ）。±180 の境目に段差・色の違いは出ない。
- 自然物：第3層（32マスの区画・座標のハッシュ）がそのまま広がる。長方形の中の候補は以前の決まり、外の候補は円の決まりで選び、外の候補は長方形の中の候補に必ず譲る（ID を守る）。
- 採取・建築の状態：自然物の ID で `S.nature` に入るので、外の野でもセーブ・再読み込み・再訪で戻る（テストで検査）。セーブの形式・版は変えていない。
- 半径 250 の理由：描画モジュールの全面の水面は ±380、遠景の山並みは中心から 262 より外。これより広げるにはモジュール側の対応が要る（CLAUDE-TO-MUSE §24）。
- 未対応（無限の世界に要るもの）：地形区画の範囲を広げる公開の口、水面・遠景の山並みの追従、遠い区画の自然物・地形のキャッシュの解放、長距離での座標の精度（原点の付け替え）、地図の自動の広がり。
