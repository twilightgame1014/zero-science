# 天然資源から宇宙到達まで

実装の正本は `src/game/data.js` と `space-data.js`。数量・設備・道具・必要実習・生成数・時間は `../space-dependencies.json` にそのまま出力してあり、画面では部品の材料を押すと既存レシピと天然資源へ逆引きできる。IDを新設し直さず、既存の採集・加工・工作を使う。

|分野|つながりと役割|必要な設備・確認|
|---|---|---|
|原料|鉄鉱・銅鉱・ボーキサイト・石英・石灰石・石油・硫黄・植物原料を既存地域で採集|採集道具は各資源の既存条件。地域の文明段階ロックなし|
|金属と構造|既存の鉄・鋼・アルミ→外装板、構造フレーム、締結部品→機体構造・発射台|精密加工台で形を揃え、材料評価台で用途適合を確認。軽さ・荷重支持・接続を分ける|
|ガラスとセラミック|石英などの既存ガラス工程→透明保護材。既存セラミック工程→耐熱セラミック|窓の見通し・保護と熱を受ける面を区別。普通の土器を直接高性能装備とはしない|
|高分子と繊維|石油加工→合成ゴムのもと→ゴム→柔軟シール材。既存布・高分子→機能繊維・気密膜・積層断熱材|気密・保護・断熱の役割を分け、加工台と評価台を使う|
|電力|既存の水力発電・導線→被覆配線、蓄電モジュール、配電ユニット|電源組立台。電源と配線の機能試験。発電機を万能な材料の代用にしない|
|電子と計算機|導体・絶縁体→切替素子→論理ゲート→加算回路・記憶回路→演算制御・入出力→学習用計算機→船内計算機|電子部品製造設備、計算機組立台、8実習。砂から直接CPUを作らない|
|宇宙服|内側衣服・気密層・保護層・ヘルメット・手袋靴・通信・生命維持→組立済み宇宙服|宇宙服組立台。装着と試験が別条件。男女で同一進行|
|生命維持|呼吸環境供給、空気再生、水衛生、温度管理、蓄電・監視→生命維持ユニット|機能ごとの素材を要求。現実の呼吸ガス・圧力・運転条件はモデル化しない|
|射点と機体|発射台・塔通路・管制・配電をマップに設置。構造から始め9スロットを組む|占有・地形・重複を検査。S0〜S4を表示。順序を飛ばした部品を宙に浮かせない|
|試験と到達|電力、計算機、通信、宇宙服、生命維持、無人模擬、総合点検→搭乗→発射|問題に対応する工程を選ぶ。確率全損なし。交換・移設で関連試験失効|

各材料の使用理由と工程の簡略化は `space-science.js` で図鑑・工作画面へ反映。全工程・数量・待ち時間はゲーム内規格。架空推進モジュールとカートリッジは現実の配合・寸法・製造条件・誘導コードを表さない。

計算機の実習はスイッチとランプ、切替素子、AND/OR/NOT、二進数加算、保存と読出し、演算/制御/記憶/入出力、簡単な命令列、架空センサーの8段階。最終計算機は状態表示と試験記録のために使う。

最終到達は宇宙場面への連続演出。軌道投入・帰還は初回条件に含めない。発射前保存、再読込み、スキップ、初回クリア記録、報酬重複防止を維持。エンディング後は「打ち上げ前の時間に戻る」ことを明示して地上を続行する。

科学説明の参考：NASA [宇宙服の役割](https://www.nasa.gov/humans-in-space/what-is-a-spacesuit/)・[ECLSSの機能](https://www.nasa.gov/reference/environmental-control-and-life-support-systems-eclss/)、Intel [半導体製造の概観](https://www.intel.com/content/www/us/en/support/articles/000096573/processors.html)、IUPAC [加硫の定義](https://goldbook.iupac.org/terms/view/VT07153/html)。ゲームの架空レシピはこれらの製造手順を再現したものではない。
