## 実装の正本

- `src/game/space.js`：製作・実習・設置・組立・試験・搭乗・演出状態。DOMや正式モデルに依存しない。
- `src/game/space-ui.js`：宇宙プロジェクト、材料から原料への逆引き、8実習、7試験、打ち上げ・探索継続。

- セーブはv5へ移行。`space`を追加し、既存の主人公・在庫・建物・探索記録を保持。通常と検証の保存キーは従来どおり分離。

## 一本の進行

既存の採集・実験で鋼、アルミ、ガラス、銅線、樹脂、布、半導体材料を得る → 精密加工台・材料評価台 → 電源／電子部品／宇宙服・生命維持の製造設備 → 回路の実習 → 学習用・船内コンピューター → 機体部品と地上設備 → マップに発射サイトを設置 → 部品組込・宇宙服装着 → 電源・計算機・通信・宇宙服・生命維持・無人模擬飛行・総合点検 → 搭乗口へ移動 → 保存・搭乗・打ち上げ → 宇宙到達・初回実績 → 打ち上げ前の時間へ戻って探索継続。

発電は既存`generator`、原料加工は既存の工作・実験・採集地点を再利用。新規の高精度工程は専用設備を要求。文明レベルの一律ロックは追加しない。宇宙服と機体に別々の生命維持ユニットが必要。
既存`oxygen`は発見記録専用で在庫不可なので、呼吸環境供給部は水・容器・シールと電解設備を使い、得た気体を直接移す工程を抽象化している。現実の呼吸ガス調整・高圧装置の製法を示さない。

全追加工程の説明に「ゲーム内で簡略化」を表示。推進は架空モジュールと架空カートリッジ。実在推進剤の配合・寸法・加工条件・誘導コードはない。命令実習のCPUは整数のLOAD/ADD/STORE/READ/OUTだけで、飛行制御には接続しない。

## 保存・試験の契約

部品は組込時に消費し、取外しで同じ部品を返す。構造は他の部品をすべて外してから外す。試験には設置位置・部品の変更番号・前提試験の署名を記録し、関連部品交換／移設後は失効する。失敗で部品を破壊しない。
打ち上げ前の保存に失敗すると発射しない。演出は保存時刻から復帰でき、スキップも同じ到達処理を使う。二重発射を拒否。初回クリア記録と再演出は別。打ち上げで資材や報酬は生成しない。
